# SOC Incident Investigation – Phishing Attack

## Overview

This project simulates a cybersecurity incident involving a phishing attack against a fictional company.

The investigation focuses on identifying the initial attack vector, analyzing suspicious authentication activity, identifying Indicators of Compromise (IoCs), assessing the potential impact, and recommending appropriate security controls.

## Scenario

An employee of a fictional company receives a suspicious phishing email.

The employee clicks on a malicious link and enters their corporate credentials on a fraudulent website.

Shortly afterwards, the security team detects multiple failed login attempts followed by a successful login from a suspicious IP address.

The security team begins an investigation to determine:

- How the attack occurred
- Which systems or accounts may have been compromised
- Which Indicators of Compromise can be identified
- What the potential impact is
- Which actions should be taken to contain and remediate the incident

## Objectives

The objectives of this investigation are:

1. Identify the initial attack vector.
2. Analyze the suspicious authentication activity.
3. Identify potential Indicators of Compromise.
4. Create an incident timeline.
5. Assess the severity and potential impact.
6. Recommend containment and remediation measures.

## Investigation Approach

The investigation will examine:

- Phishing email characteristics
- Authentication logs
- IP addresses
- User activity
- Indicators of Compromise
- Incident timeline
- Security controls

## Incident Classification

**Incident Type:** Phishing / Credential Compromise

**Severity:** High

**Status:**Contained – Further Investigation Recommended
